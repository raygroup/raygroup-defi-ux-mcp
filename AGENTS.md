# Ray Group DeFi UX MCP server

TypeScript MCP server (stdio) exposing the Ray Group DeFi UX rubric, patterns, glossary and
personas; Pro tier unlocks with `RAYGROUP_API_KEY` (sold at raygroup.uk). Source in `src/`, build
output in `dist/`, launch article in `docs/`.

`README.md` is the reference for tools, tiers, install and client config. Workspace-wide context
(decisions, plans) is in `../context/`; see `../AGENTS.md`.
